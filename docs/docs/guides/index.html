    Guides

    Install kuma-migrator, run it against your control planes, plan an upgrade, and apply the result.

    The guides cover the tool itself: how to install it, how to run each command, what it writes, and how to use its output to plan and carry out an upgrade. For what happens to a specific resource kind, see the policy pages; for one area of the mesh across kinds, see the topics.
