    Documentation

    How to use kuma-migrator to move Kuma and Kong Mesh manifests across the 2.x API changes and into 3.0.

    kuma-migrator reads the resources of a running Kuma or Kong Mesh control plane, rewrites them for the latest 2.x line or for 3.0, and writes a report of every change, every warning and every step left to you. It never writes to a control plane: you review the output and apply it yourself.

    Quick start

    brew install --cask bcollard/kuma-migrator/kuma-migrator
kuma-migrator extract --kube-context prod-eks --output-dir ./raw-policies
kuma-migrator migrate --input-dir ./raw-policies --output-dir ./migrated --dry-run
kuma-migrator migrate --input-dir ./raw-policies --output-dir ./migrated
less ./migrated/migration-report.md   # follow its Apply Checklist

    Add --to-latest v3 to migrate to target Kuma / Kong Mesh 3.0. Start with Getting started for your setup.
