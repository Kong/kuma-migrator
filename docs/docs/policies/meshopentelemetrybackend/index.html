    MeshOpenTelemetryBackend

    A shared OpenTelemetry collector endpoint referenced by MeshMetric, MeshTrace and MeshAccessLog.

    Kuma

    Behaviour per target

    --to-latest v2 (2.x) passthrough

    Output: MeshOpenTelemetryBackend

    Copied unchanged. Not generated under v2: the resource does not exist before 2.14.

    --to-latest v3 (3.0) passthrough

    Output: MeshOpenTelemetryBackend

    Copied unchanged. Also generated, one per inline openTelemetry.endpoint found in a MeshMetric, MeshTrace or MeshAccessLog: named <policy>-otel, in kuma-system on Kubernetes, protocol grpc, selected from the policy by kuma.io/display-name.

    Timeline

    VersionChange
    2.14Introduced.
    3.0Backends referenced by backendRef always export through kuma-dp.
