    Policies · Mesh* policies

    MeshCircuitBreaker

    Connection limits and outlier detection on inbound (rules[]) and outbound (to[]) traffic.

    Kuma

    Behaviour per target

    --to-latest v2 (2.x) rewritten

    Output: MeshCircuitBreaker

    Same rewrites as MeshTimeout: from[] → rules[], a <name>-outbound split when to[] is also present, and Subset-scenario ref rewrites.

    --to-latest v3 (3.0) rewritten

    Output: MeshCircuitBreaker

    v2 rewrites plus labels-only refs and control-plane label removal. Allowed to[].targetRef.kind: Mesh, MeshService, MeshExternalService, MeshMultiZoneService. MeshHTTPRoute is rejected by 3.0 and reported.

    Timeline

    VersionChange
    2.10rules[] API added; from[] deprecated.
    3.0from removed. to[] no longer accepts MeshHTTPRoute.
