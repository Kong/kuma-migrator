    --to-latest v2 (2.x) warned

    rules[].types naming a type removed in 3.0 is reported (3.0 rejects it with invalid resource type).

    --to-latest v3 (3.0) rewritten

    Output: AccessAudit

    rules[].types rewritten: legacy types renamed to their Mesh* successor (TrafficLog → MeshAccessLog), types with no successor removed, duplicates collapsed.
