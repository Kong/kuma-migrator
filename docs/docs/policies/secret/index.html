    Secret

    Mesh-scoped (Secret) or global (GlobalSecret) secret material.

    Kuma

    Behaviour per target

    --to-latest v2 (2.x) skipped

    No output kind.

    Secret and GlobalSecret are on the default skip list in both environments and are never extracted, so no secret material is written to disk.

    --to-latest v3 (3.0) skipped

    No output kind.

    Skipped. After moving off Mesh.spec.mtls, delete the <mesh>.ca-builtin-cert-<backend> / <mesh>.ca-builtin-key-<backend> secrets yourself; the upgrade does not remove them.
