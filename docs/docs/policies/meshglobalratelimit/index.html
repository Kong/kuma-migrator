    MeshGlobalRateLimit

    Kong Mesh rate limiting backed by an external rate-limit service shared across proxies.

    Kong Mesh

    Behaviour per target

    --to-latest v2 (2.x) warned

    Output: MeshGlobalRateLimit

    Copied unchanged with an advisory: removed in 3.0 with no in-mesh replacement. A leftover object is not rejected; it enforces nothing. Plan rate limiting at the gateway or with MeshRateLimit.

    --to-latest v3 (3.0) removed

    No output kind.

    Copied to _manual/, not to the apply tree, and listed under "Delete Before Upgrading to 3.0". Remove the ratelimit.* / global.ratelimit.* Helm overrides, and delete the meshglobalratelimits.kuma.io CRD after upgrading (Helm leaves it in place).

    Timeline

    VersionChange
    3.0Removed with its control-plane support, the Helm rate-limit service and the KMESH_GLOBAL_RATE_LIMIT_* settings. Leftover objects become inert.
